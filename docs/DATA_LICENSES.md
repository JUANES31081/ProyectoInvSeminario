## Reglas aplicadas en este repositorio

1. Los datos descargados NO se versionan en Git (ver `.gitignore`).
2. Cada carpeta de descarga mantiene un `SOURCE_PATH.txt` con la fuente real.
3. Los resultados publicados aqui son metricas derivadas (conteos, shapes), no
   redistribucion de los datos originales.
4. Para uso comercial o redistribucion, debe obtenerse permiso del titular de cada dataset.
